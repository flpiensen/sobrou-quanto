# ⚠️ Pasta de protótipo (não é código da aplicação)

Os arquivos `code.html` e `screen.png` desta pasta são o **export bruto do Google Stitch** (ferramenta de IA generativa usada na fase de prototipação da Entrega 1).

- O Stitch sempre gera as telas usando **Tailwind CSS** internamente — isso é uma característica da ferramenta, não uma escolha do projeto.
- Este conteúdo serve **apenas como referência visual e de design system** (ver `../docs/sdd.md`).
- Nenhum arquivo daqui é importado ou executado pela aplicação real (`index.html`, `pages/`, `css/`, `js/`).
- Na **Entrega 2**, essas telas serão reimplementadas do zero em HTML5 + [MaterializeWeb](https://materializeweb.com/) (o framework CSS oficialmente escolhido para o projeto — ver `../docs/architecture.md`), sem nenhuma dependência do Tailwind.
